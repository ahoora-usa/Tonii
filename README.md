# Tamu Girl - فروشگاه لوازم آرایشی

یک سایت مدیریت محصولات آرایشی با قابلیت افزودن، ویرایش و حذف محصولات به همراه آپلود چندین عکس برای هر محصول.

## ویژگی‌ها

- ✅ پنل مدیریت اختصاصی با ورود امن
- ✅ افزودن محصول با نام، قیمت، تخفیف و توضیحات
- ✅ آپلود چندین عکس برای هر محصول
- ✅ نمایش تصاویر در لیست محصولات
- ✅ حذف محصولات از لیست
- ✅ بخش اختیاری برای یادداشت‌ها و تغییرات دلخواه
- ✅ ذخیره خودکار اطلاعات در مرورگر (localStorage)
- ✅ طراحی واکنش‌گرا و مناسب برای موبایل
- ✅ تم صورتی و جذاب

## نحوه استفاده

1. روی دکمه **مدیریت** در بالای صفحه کلیک کنید
2. با یکی از حساب‌های کاربری بالا وارد شوید
3. در پنل مدیریت:
   - نام، قیمت، تخفیف و توضیحات محصول را وارد کنید
   - چندین عکس از محصول را انتخاب کنید
   - روی دکمه **افزودن محصول** کلیک کنید
4. محصولات افزوده شده در لیست زیر نمایش داده می‌شوند
5. برای حذف هر محصول، روی علامت ✕ کلیک کنید
6. در بخش **اختیاری** می‌توانید هر یادداشت یا تغییری را ذخیره کنید

## تکنولوژی‌های استفاده شده

- HTML5
- CSS3 (با Flexbox و Grid)
- JavaScript (خالص، بدون کتابخانه)
- localStorage برای ذخیره داده‌ها
- GitHub Pages برای میزبانی
